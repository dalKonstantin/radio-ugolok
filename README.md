# Radio Ugolok

Внутреннее офисное веб-радио: один общий эфир, который все слушают в наушниках синхронно.

> Сейчас готовы этапы **M1 — синхронизация** и **M2 — библиотека и загрузка**. Очереди ещё
> нет (M3): в эфире по кругу крутится один трек (по умолчанию — сгенерированный метроном),
> загруженные треки видны в библиотеке и открываются как файл.

## Запуск

Нужны Go 1.23+ и `ffmpeg`/`ffprobe` в PATH.

```sh
make run          # http://localhost:8080
make build        # один бинарник в bin/radio
```

Свой трек в эфир вместо метронома: `go run ./cmd/radio -track path/to/song.flac`.

Флаги (или переменные окружения `RADIO_*`): `-addr`, `-data`, `-max-upload` (МБ), `-bitrate` (kbps).

## Загрузка

`POST /api/upload` (multipart, поле `file`, необязательное `nick`) или кнопка «Загрузить трек».
Формат определяется по содержимому через `ffprobe`: mp3, flac, wav, aiff, ogg Vorbis, opus,
m4a (AAC/ALAC), wma. Всё перекодируется в эфирный MP3 CBR 44,1 кГц стерео и кладётся в
`data/tracks/<sha256 исходника>.mp3`; исходник не хранится. Тот же файл второй раз не
создаёт дубль. Теги и обложка читаются из оригинала, обложка — `data/covers/<id>.jpg`
до 500×500, пики waveform (1000 байт) — в SQLite `data/radio.db`.

```sh
curl -F nick=kostya -F file=@song.flac localhost:8080/api/upload
curl 'localhost:8080/api/library?q=город'
```

## Как работает синхронизация

Сервер не стримит аудио: он рассылает по WebSocket, какой трек играет и с какой серверной
отметки времени (`startedAt`). Клиент оценивает сдвиг своих часов относительно сервера —
10 обменов ping/pong, медиана трёх с наименьшим RTT, повтор раз в минуту. Позиция эфира —
`(Date.now() + offset - startedAt) / 1000`; клиент перематывает `<audio>` в неё с запасом
0,3 с и запускает воспроизведение, когда эфир догонит запас. Дальше на каждом `timeupdate`
он меряет дрейф: до 50 мс ничего не делает, до 1 с подстраивает `playbackRate` в пределах
±2 %, больше — перематывается жёстко. Сам файл едет обычным HTTP с `Range` и кешируется навсегда.

## Проверка

```sh
make test         # go vet, go test (форматы, дедупликация, поиск), node --test (offset, дрейф)
```

Вживую (критерий M1): открыть страницу на двух машинах или в двух разных браузерах,
нажать «Подключиться» — метроном щёлкает в унисон, `drift` в блоке диагностики держится
в пределах ±50 мс. Искусственный дрейф из консоли: `radio.audio.currentTime += 3` —
должен выправиться сам.
